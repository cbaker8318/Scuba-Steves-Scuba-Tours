# Scuba Steve's Scuba Tours

## Project Overview

Scuba Steve's Scuba Tours is a two-page website designed to introduce visitors to a fictional scuba diving tour business and provide basic information about its scuba diving tours and excursions.

The project was created using HTML, CSS, Markdown, GitHub, and GitHub Pages.
