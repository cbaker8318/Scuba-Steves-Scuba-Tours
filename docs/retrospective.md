# Project Retrospective

## Project Title

**Scuba Steve's Scuba Tours Website**

## What Went Well?

Overall making the website went pretty well.  I like how the underwater theme was consistant on both pages.  I think adding a graphic as the background gave it a professional look. Also using a transparent backgrounds really made the text stand out and easier to read.

## What Went Wrong?
I struggled with setting up my repository. Originally it was in another projects subfolder and I did not realize it. This was causing everything to be disorganized and could of caused problems when I published it. I had to move the entire project to a folder of its own to allow for proper publishing. While this was an easy fixable problem it did require extra time to troubleshoot and test.

## What Would I Do Differently?

The main thing I would do different would be to make sure my project is in its own repository when I start it. This would have saved time causing less troubleshooting and testing. That time could have been used to add additonal feature such as drop down menus to my website.
