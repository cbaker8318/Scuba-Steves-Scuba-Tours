# Project Title

**Scuba Steve's Scuba Tours Website**

## Project Purpose

To create a two-page website for Scuba Steve's Scuba Tours. The website will introduce the business to potential customers and provide basic information about the scuba diving tours and excursions offered.

## Project Goals

- Create a simple and professional website for Scuba Steve's Scuba Tours.
- Create an ocean and scuba diving theme that is consistent throughout the website.
- Provide easy navigation between the website's two pages.
- Apply the HTML, CSS, Markdown, and GitHub techniques learned in this course.

## Completed Project

- A public GitHub repository.
- A professional README file explaining the project and providing links to the live website.
- An index.html file to create a homepage for Scuba Steve's Scuba Tours.
- An about.html second page linked on the home page.
- A style.css file that provides consistent styling for both webpages.
- A docs folder containing my scope, plan and retrospective files.
- A published version of the website that can be accessed online.

## Exclusions

- Online tour reservations.
- Online payments.
- Customer accounts or logins.
- Equipment rental reservations.
- Real-time tour availability.
- Additional webpages.

## Potential Challenges

- Time managment between planning, testing, and documentation.
- Troubleshooting any errors.
- Keeping a cohesive consistant design.
- Correctly organizing files in GitHub.
